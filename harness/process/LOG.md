# Log

One entry per verified step, appended at the end, written by Claude after you report what you saw.
Your words stay your words. Each entry is also a commit (`Step k.n: <name>`), so you can go back to any
step. The "repeated or corrected" line is the raw material for your own harness: anything you had to
say twice is a rule waiting to be written. `/retro` reads these lines back to you.

One log for the whole project. Every round starts with its own `# Round k` line, so the log reads as the
story of how the idea grew. Entry shape, where `k` is the round and `n` the row in that round's plan:

```
## YYYY-MM-DD · Step k.n · <step name>
- Student decided: …
- Claude decided: …
- Repeated or corrected: … (or "none")
- Unreported: … (only if a "look for" question went unanswered; it returns on the next handover)
- Then: … (a tweak that rode along with the next step)
```
